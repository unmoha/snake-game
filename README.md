## Features

- Classic Snake gameplay with a neon look
- Keyboard (arrow keys) and WASD controls
- Touch controls for phones and tablets
- Pause and restart at any time

## Controls

| Action | Keys |
|---|---|
| Move | Arrow keys or `W` `A` `S` `D` |
| Pause | `Space` |
| Restart | `R` |
| Mobile | Touch controls on screen |

## Run locally

From the project directory, start a local server:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` in your browser.
